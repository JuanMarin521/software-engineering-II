# Pruebas funcionales (RTF4, caja negra)

Catalogo de 92 casos de prueba (CP-01 a CP-92) del Gemelo Digital, disenados desde la interfaz del usuario.

- `catalogo_casos.csv`: casos con HU, caso de uso, tipo, entrada, resultado esperado, prioridad, criterio de aceptacion y herramienta.
- Documento de diseno: `docs/RTF4-Diseno-Pruebas-Funcionales.docx`.
- Trazabilidad: cada CP-xx corresponde a una subtarea en Jira (SCRUM-66 a SCRUM-70).

Estado: diseno completo. La ejecucion con Playwright depende de la capa HTTP y el tablero web (SCRUM-73).
